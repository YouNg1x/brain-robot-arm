# Brain Robot Arm

面向 PiPER 机械臂的视觉与脑机接口实验工程，包含 ROS 2 工作空间、相机驱动、仿真/真机演示、控制站和实验脚本。

## 目录

- `piper_ws/`：PiPER 抓取与放置相关 ROS 2 包。
- `ros2_ws/`：相机与视觉相关 ROS 2 包。
- `control_station/`：控制站工具。
- `scripts/`：启动、测试和辅助控制脚本。
- `docs/`：设计说明、验证边界与实验记录。
- `vendor/`：第三方依赖源码及其许可证。

## 安全边界

仿真、视觉和真机控制应保持分离。实体机械臂运行前必须完成相机外参、关节限位、速度上限、工作空间、急停和人工确认验证；未完成现场验证前，不应自动解锁完整抓取流程。

## 说明

仓库不包含本地 Conda 安装包、缓存、编译输出和运行记录。第三方目录中的许可证文件应与对应源码一并保留。
