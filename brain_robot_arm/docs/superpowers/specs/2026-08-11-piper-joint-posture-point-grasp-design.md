# PiPER 关节换姿态与水平点位抓杯设计

## 1. 目标与替换范围

替换已实现流程中的 `LEVEL_ALIGN -> FINAL_APPROACH` 笛卡尔 Servo 最后接近。新的抓取阶段以绿色图像中心 `(320,240)` 为唯一视觉目标：识别到杯子并到达安全距离后，J2 增大、J3 减小、J5 从正角度向负角度上抬，同时用视觉反馈维持杯子在绿色中心。姿态稳定后停止 Servo，再由 MoveIt2 规划并执行一次水平点位侧抓；闭爪、附着杯子、竖直抬升并保持。

J5 的 Gazebo 正方向已经验证为相机向下看。因此“J5 上抬”在本流程中明确为 J5 角度减小并跨过零位至负角度，不能使用原有的 J5 正向搜索含义。

本阶段只覆盖单个红杯的仿真侧抓和抬升到 `HOLDING`，不包含转移、放置、实体机械臂解锁或头环 SDK 接入。

## 2. 状态与职责

状态流调整为：

`SEARCH -> ALIGN -> APPROACH -> GRASP_POSTURE -> POINT_GRASP -> CLOSE -> ATTACH -> LIFT -> HOLDING`

`visual_search_controller` 继续负责搜索、以绿色中心为目标的视觉误差处理，以及 `GRASP_POSTURE` 中的关节速度命令。它不闭合夹爪，也不直接调用 Gazebo 服务。

`grasp_lift_executor` 在 `GRASP_POSTURE` 时开爪并暂时移除 MoveIt 杯子碰撞体；只有收到 `POINT_GRASP` 授权后才计算点位抓取目标、调用 MoveIt2、闭爪、附着和抬升。Gazebo 杯子跟随仍限定在仿真执行器内。

## 3. GRASP_POSTURE：视觉锁定下的关节换姿态

进入条件是杯子已在绿色中心死区内、深度有效，并已到达原有安全距离。此阶段禁止沿相机方向前进。

- J1 继续根据水平像素误差做小幅修正。
- J2 向正方向移动到参数化的抓取姿态目标。
- J3 向负方向移动到参数化的抓取姿态目标。
- J5 向负方向移动到参数化的水平抓取姿态目标，必须允许跨过 `0 rad`。
- J4/J6 保持现有画面滚转约束；它们不承担 J5 上抬动作。

控制器每个周期读取关节状态与目标像素。J2/J3/J5 的姿态速度受独立上限约束；J1 只做视觉闭环补偿。杯子连续稳定在绿色中心、J2/J3/J5 均进入各自角度容差、深度仍有效后，发布零速度并进入 `POINT_GRASP`。

J2/J3/J5 目标角度、速度、容差均为 Gazebo 配置参数。实现前先从现有 URDF/ros2_control 关节限位读取允许范围，不能把后续实体标定值复制到仿真或反向使用。

## 4. 水平点位抓取

点位目标不能沿用最后一次 Servo 速度命令。检测器增加对相机 `CameraInfo` 的读取，以 RGB 像素、有效深度和内参计算杯子相机坐标点：

`X = (u - cx) * Z / fx`，`Y = (v - cy) * Z / fy`，`Z = depth`。

执行器通过 TF 将该点变换到世界坐标系。夹爪目标姿态以世界坐标约束构造：夹爪前进方向位于桌面平面内，画面上方对应世界 `+Z`，因此夹爪保持水平；偏航使用视觉锁定阶段的相机朝向和相机—夹爪外参得到，不沿用当前可能倾斜的末端姿态。

执行器将杯子三维点减去已标定的“杯心到 `gripper_base`”侧抓偏移，形成 MoveIt2 的 `PoseStamped` 目标。MoveIt2 从当前抓取姿态规划到该目标，速度与加速度继续使用低值限制。规划成功并执行完成后才允许闭爪。

仿真偏移是可调参数；实体 Gemini2 必须单独标定相机内参、相机相对夹爪外参、杯心检测偏差和夹爪侧抓偏移。单个红色区域的中位深度在真实装水杯上不必然等于杯心，实体阶段需要通过标定补偿，不能把仿真抓取偏移当作实测事实。

## 5. 安全和失败路径

- 任何目标、深度、CameraInfo、TF 或关节状态超时均立即停止，禁止进入 `POINT_GRASP` 或闭爪。
- 点位规划失败、目标超出工作空间、姿态不水平或碰撞检查拒绝时，不闭爪；如果杯子碰撞体已经临时移除，则恢复它。
- 闭爪后附着失败，保持停止，不把 Gazebo 杯子伪造为已经抓住。
- 已附着后的抬升失败，保持闭爪与附着，等待用户停止或重置场景。
- 仿真一键启动允许自动执行；实体 PiPER/Gemini2 配置继续由 `real_motion_enabled=false`、`simulation_only=false` 和 `auto_execute=false` 锁定。

## 6. 验证顺序

1. 仅构建 `brain_robot_pick_place`，确认新增相机内参订阅、状态和执行器可启动。
2. Gazebo 观察 `GRASP_POSTURE`：J2 增大、J3 减小、J5 从正值经过零到负值；杯子仍在绿色中心死区。
3. Gazebo 检查点位规划轨迹：夹爪全程保持世界水平，终点杯身位于两片夹爪之间。
4. Gazebo 执行闭爪、附着、杯子跟随和世界 `+Z` 抬升，最终状态为 `HOLDING`。
5. 单独记录 Gazebo 结果。它不代表 Gemini2、实体 PiPER、装水杯、SSVEP 或 EOG 已验证。
