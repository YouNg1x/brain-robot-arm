# PiPER腕部相机目标居中视觉伺服设计

## 目标与范围

在Gazebo中的PiPER夹爪上增加虚拟RGB-D相机，令相机光轴与夹爪前进轴重合。机械臂先由MoveIt2移动到观察位置，再根据目标在相机画面中的位置和深度连续调整末端，使目标保持在画面中央并缓慢接近。达到抓取距离后停止视觉伺服、闭合夹爪，再复用现有抬升、转移、放置和轨迹显示流程。

第一版仅用于Gazebo中的红色圆柱杯，不控制真实机械臂。真实Gemini2接入、相机内外参标定、多类别识别、SSVEP目标选择和EOG执行确认不属于本次实现范围，但本次节点接口应允许后续替换数据源。

## 坐标假设

第一版假设相机光轴与夹爪前进轴完全重合，相机安装位置相对 `gripper_base` 固定。目标位于画面中心等价于夹爪正对目标。相机绕自身光轴的滚转不由画面中心唯一确定，因此视觉伺服只修正水平朝向、垂直朝向和前后距离，滚转角保持稳定。

## 系统组成

### 虚拟腕部相机

在自有仿真描述中为 `gripper_base` 增加固定的相机链接和Gazebo RGB-D传感器，不直接破坏官方PiPER源文件。相机发布彩色图、深度图和相机内参，并提供与 `gripper_base` 的固定TF。第一版分辨率和帧率以虚拟机可稳定运行优先，目标为640×480、15至30 Hz。

### 红杯检测节点

订阅彩色图和对齐深度图，使用HSV颜色分割、形态学去噪和最大有效轮廓提取红杯。输出目标中心像素 `(u,v)`、中心邻域深度、检测置信状态和带中心十字及包围框的调试图像。深度使用中心邻域中值，避免单个无效深度像素导致跳变。

### 视觉伺服节点

视觉伺服节点接收目标像素、深度和相机内参，以画面中心 `(cx,cy)` 为期望值。归一化图像误差为 `ex=(u-cx)/fx`、`ey=(v-cy)/fy`，距离误差为 `ez=depth-desired_depth`。控制器以限幅比例控制生成低速末端速度：水平误差控制偏航，垂直误差控制俯仰，距离误差控制沿相机光轴前进；误差位于死区内时停止对应方向。

末端速度交给MoveIt Servo执行，由其负责关节速度限制、奇异点抑制和碰撞检查。视觉检测与控制解耦：图像节点按相机帧率工作，控制节点以固定频率读取最近一次有效目标，不在图像回调中直接执行耗时规划。

### 任务状态机

状态顺序为 `IDLE -> MOVE_TO_OBSERVE -> TRACK_AND_APPROACH -> GRASP -> LIFT_AND_PLACE -> COMPLETE`。MoveIt2负责观察位姿和抓取后的轨迹，MoveIt Servo只负责视觉对准与接近。进入抓取距离且像素误差连续稳定若干帧后才允许夹紧，避免机械臂在目标尚未居中时抓取。

## 安全与异常处理

目标丢失、图像超时、深度无效、深度突变、MoveIt Servo停止或关节接近限制时，立即发布零速度并停留，不沿最后一次方向继续运动。视觉伺服速度、角速度和单次运行时间均设上限。第一版保留键盘或ROS服务停止入口；SSVEP和EOG后续只能触发或取消高层任务，不能绕过安全状态直接发送关节命令。

## 可观察输出

Gazebo显示机械臂、桌子和红杯；相机调试窗口显示实时腕部视角、画面中心十字、目标轮廓、目标中心、像素误差和深度。RViz继续显示机器人、碰撞场景和规划轨迹。终端输出状态切换、目标误差、目标丢失及停止原因，便于逐阶段定位问题。

## 实施顺序与验证标准

1. 先安装虚拟腕部相机并验证图像随夹爪运动、红杯能够进入视野。
2. 再实现红杯检测，验证静止机械臂下目标中心和深度稳定。
3. 接入仅旋转的视觉对准，验证夹爪能把杯子转到画面中心。
4. 增加低速前进，验证接近过程中杯子持续保持在中心附近。
5. 达到距离和稳定帧条件后接入夹紧，并复用现有抬升与放置流程。

本阶段通过条件为：目标检测稳定；目标偏离画面中心时机械臂向正确方向修正；目标丢失时立即停止；接近过程中不持续振荡；达到抓取条件后能够夹住杯子并完成原有取放。Windows侧静态检查、Ubuntu编译、Gazebo闭环验证和真实Gemini2验证必须分别记录，不能相互替代。
