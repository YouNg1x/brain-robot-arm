# 点云环境建模与实体紫色方块抓取规划设计

## 目标

解决实体 PiPER 当前“视觉对齐后只尝试一个固定末端目标，遇到关节限制或路径障碍就抓取失败”的问题。新流程必须在执行前同时考虑：机器人关节限制、机器人自身碰撞、桌面/线缆等环境障碍、紫色方块尺寸和相机—机器人外参。

## 设计边界

第一阶段不迁移到完整 MoveIt Task Constructor，也不改变现有视觉搜索和数字键交互。保留现有 `1` 零点复位后搜索、`2` 请求抓取、`0` 零点复位、Ctrl+C 失能的行为。只重构抓取前的环境建模、目标碰撞盒、候选姿态选择和真实执行确认。

## 数据流

```text
Astra depth / PointCloud2
  -> TF: camera_color_optical_frame -> base_link
  -> 机器人自身点云过滤
  -> MoveIt Occupancy Map Monitor / OctoMap
  -> Planning Scene

紫色检测器 target_point_camera + target_size
  -> TF 到 base_link
  -> 方块 box CollisionObject
  -> 抓取候选姿态生成
  -> IK、关节限制、碰撞和路径规划筛选
  -> 预抓取 -> 直线接近 -> 闭爪 -> 附着 -> 抬升
```

## 环境点云

优先使用 MoveIt 官方 `PointCloudOctomapUpdater` 或 `DepthImageOctomapUpdater`，不在抓取执行器中自行实现完整八叉树。占据地图的固定坐标系使用 `base_link` 或项目实际固定基座坐标系；传感器输入必须带有效时间戳和 TF。必须启用机器人自过滤，并通过 RViz/调试话题确认桌面和明显障碍物确实进入 Planning Scene。

由于相机安装在机械臂上，点云只是当前视角的局部环境，不承诺一次覆盖整个工作区。规划前应使用最近一帧稳定点云；相机运动后必须等待 TF 和占据地图更新完成，不能把旧视角点云当作当前环境。

## 紫色方块碰撞模型

由 `target_point_camera` 和 `target_size` 变换到 `base_link` 后，创建一个以方块中心为位置、以检测尺寸为边长的 box `CollisionObject`。抓取前该物体作为世界碰撞物存在；夹爪接近和闭合阶段只允许经过明确配置的夹爪—方块接触；闭爪成功后将其转换为 attached collision object。目标点过期、尺寸过期或 TF 失败时，不允许规划或闭爪。

## 多候选抓取规划

不再假设“视觉居中就可以直线抓取”。以方块中心和当前末端状态为输入，生成有限数量的候选末端姿态，包括相机前方斜向姿态、左右侧斜向姿态和不同腕部 yaw。每个候选按以下顺序筛选：

1. 目标姿态坐标系和 TF 有效；
2. 逆运动学存在解；
3. 关节不接近 PiPER 软件/硬件限制；
4. 预抓取位姿和整段路径无自碰撞、OctoMap 碰撞或桌面碰撞；
5. 预抓取到抓取点的笛卡尔接近路径比例达到阈值。

候选评分优先选择规划成功、距离当前关节状态较近、远离关节限制且预抓取高度充足的姿态。没有候选成功时只发布失败原因，不执行闭爪。

## 实体执行闭环

实体模式仍由 MoveIt 生成轨迹，再通过 `/brain_robot_grasp/arm_trajectory` 交给 `piper_jog_adapter`。但每个运动阶段都必须等待 `/joint_states` 进入目标容差：预抓取未到位不能接近，接近未到位不能闭爪，闭爪命令后不能立即宣称抓取成功。抬升后至少发布 `HOLDING`，并保留当前关节和夹爪命令诊断。

## 验收标准

1. RViz Planning Scene 可见由 Astra 点云生成的桌面/障碍物占据地图。
2. RViz 可见正确位置和尺寸的紫色方块碰撞盒。
3. 抓取日志列出候选姿态数量、IK/碰撞/规划失败原因和最终选中候选。
4. 关节限制导致某个候选失败时，系统尝试其他候选，而不是直接停止或闭爪。
5. 预抓取、直线接近、闭爪、抬升均有状态和实际关节反馈确认。
6. 点云、TF、目标点或尺寸过期时，系统拒绝抓取并保持 PiPER 当前使能状态；只有 Ctrl+C 才执行失能。

## 分阶段实现顺序

1. 先接入点云/深度图 Occupancy Map，并在 RViz 验证 Planning Scene。
2. 再加入方块 box CollisionObject 和 TF/尺寸有效性检查。
3. 再实现多候选姿态、IK 和碰撞筛选。
4. 最后替换实体抓取执行器中的单目标路径，并加入每阶段关节反馈确认。
