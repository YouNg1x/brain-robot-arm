# PiPER 杯子俯抓轨迹改造设计

## 目标

将现有的水平侧向抓杯改为竖直俯抓。夹爪从杯子正上方接近，沿世界坐标系 Z 轴下降夹住杯身，再竖直抬升并搬运到放置点。改造仅用于当前 Gazebo 仿真程序，不解除 `simulation_only` 限制。

## 原因

当前程序把启动时的末端姿态直接复制给所有目标点，因此机械臂初始夹爪水平时，整个取放过程都会维持水平姿态。侧向接近同时限制末端位置和腕部姿态，容易使腕部关节接近限位，也不利于以后根据腕部相机输出的平面目标坐标执行抓取。

## 实现设计

1. 使用固定的绝对末端姿态，使 `gripper_base` 的局部正 Z 轴朝向世界坐标负 Z 轴，即夹爪指向桌面。腕部绕竖直轴的方向使用一个参数控制，默认选择朝向机械臂基座最容易求解的方向。
2. 预抓取目标位于杯子中心正上方，并保留足够的垂直安全距离。程序不再通过 X 方向距离生成侧向预抓取点。
3. 抓取顺序调整为 `PREGRASP -> ABOVE_CUP -> DESCEND -> CLOSE -> LIFT`。其中前三个目标保持相同 X、Y 和末端姿态，只改变 Z 高度。
4. 搬运和放置顺序调整为 `TRANSFER -> LOWER -> OPEN -> RETREAT`。放置点上方和放置点保持相同 X、Y，松开后沿 Z 轴向上撤离。
5. 保留现有 MoveIt2 规划、Gazebo执行、杯子跟随、碰撞体附着/解除、RViz轨迹和阶段停顿逻辑。阶段名称和轨迹颜色只做与新动作对应的必要调整。

## 参数与调试边界

第一版提供俯抓姿态和三个垂直距离参数：预抓取安全高度、夹取高度、抬升高度。只在 Gazebo 中逐项调整这些参数；不得把仿真参数直接用于真实机械臂。若固定腕部朝向无法求解，只调整绕竖直轴的偏航角，不改变夹爪朝下的要求。

## 验证标准

1. 编译 `brain_robot_pick_place` 成功。
2. Gazebo 中夹爪在接近杯子前转为朝下姿态。
3. 夹爪从杯子正上方下降，不再从侧面水平接近。
4. 夹紧后杯子随夹爪竖直抬升，转移后竖直放下。
5. RViz 保留完整彩色轨迹，终端依次输出新的动作阶段。
6. 本次验证只代表仿真通过，不代表真实PiPER机械臂已经验证。
