# 紫色方块真机抓取设计

## 目标

在现有 RGB-D 视觉搜寻链路上，将“红色小球”目标替换为“紫色正方体”，并用于 PiPER 实体机械臂的首次低速测试。视觉检测、深度反投影和状态输出保持原有接口，真机运动采用保护模式：先低速视觉对准，操作者确认后才允许执行抓取。

## 检测策略

- RGB 输入使用实体 DaBai DC1 的 `/camera/color/image_raw`。
- 深度输入使用 `/camera/depth/image_raw`，仅用于 RGB 像素反投影和距离有效性判断，不作为阶段切换条件。
- HSV 使用紫色范围，允许通过参数调整色相、饱和度和值阈值。
- 候选轮廓同时满足面积范围、矩形度 `area / boundingRect.area`、长宽比范围和可选旋转矩形填充率。
- 目标标签改为 `PURPLE_CUBE`，保留 debug image、pixel error、target valid、depth valid 和 camera-frame point 话题。
- 不把 4 cm 作为固定像素面积。检测器根据深度和相机内参由方框像素宽高估算物体尺寸，并发布 `/brain_robot_vision/target_size`（宽、高、深度，单位 m）。

## 真机控制策略

- 视觉控制器使用 `backend=piper`，读取实体 `/joint_states`，但只允许低速对准阶段。
- 视觉对准速度和关节范围使用独立真机参数，不复用仿真参数。
- 目标稳定且操作者确认前，抓取执行器只发布 PREPARED/READY 状态，不发送 MoveIt 轨迹或夹爪命令。
- 需要显式的确认服务或按键触发，确认后才进入点位规划；任何目标丢失、关节状态超时、Servo 故障、规划失败或急停消息都会停止并回到安全状态。
- 抓取参数根据估算方块尺寸增加安全间隙和预抓取距离；当前保护配置只接受 1–25 cm 的估计尺寸，最终上限还必须按实体夹爪最大开口和工作空间重新标定。
- 真机配置保留默认锁定；解锁必须由单独的显式参数和运行时确认共同满足，不能仅修改 `simulation_only`。

## 验证标准

1. 在实体相机上 debug image 稳定显示紫色方块框、中心、深度和 `PURPLE_CUBE` 标签。
2. `/brain_robot_vision/target_valid`、`/brain_robot_vision/target_point_camera` 和 `/brain_robot_vision/pixel_error` 连续更新。
3. `/brain_robot_vision/target_size` 连续发布宽、高、深度，尺寸随方块实际大小变化。
4. 真机低速对准期间关节速度不超过真机配置上限，目标丢失立即停止。
5. 未收到操作者确认时，抓取执行器不发布轨迹或夹爪动作。
6. 通过确认后，先验证预抓取规划，再允许接近、闭爪和抬升；任一步失败都停止，不自动重试。

## 当前限制

实体相机到机械臂末端的外参、方块实际尺寸、夹爪接触姿态和 MoveIt 真机规划可达性必须在现场测量/验证。未完成这些验证前，不应自动解锁完整抓取流程。
